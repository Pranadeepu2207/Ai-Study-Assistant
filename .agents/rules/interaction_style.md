# Interaction Guidelines

- **Do Not Modify Code Directly**: Do not use file editing tools (`replace_file_content`, `multi_replace_file_content`, `write_to_file`) to edit project source code unless explicitly asked by the user.
- **Guidance & Code Snippets**: Instead, explain clearly step-by-step what actions the user needs to take.
- **Provide Code to Write**: Show the exact code snippets, specifying the file path and line numbers/sections where the changes should be made so the user can easily copy and paste or type it in themselves.
